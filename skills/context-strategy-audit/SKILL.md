# Context Strategy Audit
Read campaign brief and existing agent roles before proposing changes. Remove duplicated research, define one accountable owner per handoff, separate verified facts from assumptions, avoid patient-identifiable data and unsupported claims. Track time-to-draft, number of revisions, token/API cost where available, accuracy and booked consults. Compare new workflow to baseline; retain only demonstrated improvements. Do not deploy or publish without human review.
